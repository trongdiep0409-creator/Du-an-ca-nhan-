# 08 — Roadmap 30 Tháng

## 1. Overview

Roadmap 30 tháng là **cố định** trừ khi user approve thay đổi. AI chỉ được đề xuất thay đổi, không được tự thực hiện.

Mục tiêu cuối: **Digital Solutions Consultant**

## 4. Roadmap Data Model

Mỗi stage/month cần có:

| Field | Mô tả |
|-------|-------|
| Stage | Tên stage |
| Month | Tháng (1–30) |
| Milestone | Mốc quan trọng |
| Skill targets | Kỹ năng cần đạt |
| Project targets | Project cần hoàn thành |
| Evidence targets | Evidence cần tạo |
| Status | Not Started / In Progress / Completed |
| Progress | % hoàn thành |
| Revisions | Lịch sử thay đổi |

---

## 5. Roadmap Revision

### 5.1 Quy trình

```
AI observe → AI analyze → AI recommend → User review → User approve/reject
```

### 5.2 Rules

- Roadmap 30 tháng là **cố định** trừ khi user approve
- AI chỉ được **đề xuất** thay đổi
- Mọi thay đổi phải có user approval
- Revision phải được log

### 5.3 Revision Log

| Field | Mô tả |
|-------|-------|
| Revision ID | Unique ID |
| Date | Ngày thay đổi |
| Change | Mô tả thay đổi |
| Reason | Lý do thay đổi |
| AI Recommendation | Đề xuất AI (nếu có) |
| Approved By | User |
| Status | Approved / Rejected |

## 7. Adaptive State

| State | Threshold |
|-------|-----------|
| AHEAD | completion > 90%, evidence strong, low rework |
| ON TRACK | completion 70–90%, evidence acceptable |
| AT RISK | completion 40–70%, repeated rework |
| BLOCKED | completion < 40%, repeated failure hoặc thiếu prerequisite/evidence |

> Threshold chỉ là baseline; implementation sau có thể configurable.
