## 4. Roadmap Data Model

Mỗi stage/month cần có:

| Field | Mô tả | Type |
|-------|-------|------|
| Stage | Tên stage | LOCKED |
| Month | Tháng (1–30) | LOCKED |
| Milestone | Mốc quan trọng | ADAPTIVE |
| Skill targets | Kỹ năng cần đạt | LOCKED (competency) |
| Project targets | Project cần hoàn thành | ADAPTIVE |
| Evidence targets | Evidence cần tạo | ADAPTIVE |
| Status | Not Started / In Progress / Completed | Tracked |
| Progress | % hoàn thành | Tracked |
| Revisions | Lịch sử thay đổi | Log |

---

## 5. Roadmap Revision

### 5.1 Quy trình

```
AI observe → AI analyze → AI recommend → User review → User approve/reject
```

### 5.2 Rules

- AI chỉ được đề xuất thay đổi **ADAPTIVE** items
- AI **không được** tự thay đổi **LOCKED** items
- Mọi thay đổi phải có user approval
- Mọi thay đổi phải được log thành revision record

### 5.3 Revision Log

| Field | Mô tả |
|-------|-------|
| Revision ID | Unique ID |
| Date | Ngày thay đổi |
| Change | Mô tả thay đổi |
| Change Type | LOCKED / ADAPTIVE |
| Reason | Lý do thay đổi |
| AI Recommendation | Đề xuất AI (nếu có) |
| Approved By | User |
| Status | Approved / Rejected |

## 6. Weekly Capacity

| Preset | Hours | Usage |
|--------|-------|-------|
| Recovery | 8–10h | Tuần bận, cần nghỉ ngơi |
| Busy | 12–14h | Tuần bận vừa |
| Normal | 17.5h | Mặc định (5 ngày × 3.5h) |
| Sprint | 20–22h | Tuần tập trung cao độ |

**Capacity Rule:**
- Khi planned workload vượt capacity:
  - Hiển thị warning
  - Hiển thị số giờ vượt capacity
  - User có thể giảm workload HOẶC confirm override
- AI có thể đề xuất không overload
- AI không được tự chặn user

## 7. Adaptive State

| State | Threshold |
|-------|-----------|
| AHEAD | completion > 90%, evidence strong, low rework |
| ON TRACK | completion 70–90%, evidence acceptable |
| AT RISK | completion 40–70%, repeated rework |
| BLOCKED | completion < 40%, repeated failure hoặc thiếu prerequisite/evidence |

> Threshold chỉ là baseline; implementation sau có thể configurable.
