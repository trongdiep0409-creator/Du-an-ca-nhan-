# 09 — Language Track

## 1. Overview

Language là một domain thực sự trong Titan OS, không phải phụ trợ. Có 2 ngôn ngữ: **English** và **Chinese**.

---

## 2. English Track

### 2.1 Mục tiêu

- **Target ban đầu:** TOEIC 650
- **Thời gian ưu tiên:** 6 tháng đầu (FOUNDATION)
- **Sau đó:** Maintenance + Professional usage

### 2.2 Kỹ năng

| Kỹ năng | Mô tả |
|---------|-------|
| TOEIC | Luyện đề, chiến thuật làm bài |
| Listening | Nghe hiểu, nghe chủ động |
| Vocabulary | Từ vựng chuyên ngành + thông dụng |
| Reading | Đọc hiểu tài liệu kỹ thuật |
| Grammar | Ngữ pháp cơ bản + nâng cao |
| Professional English | Email, meeting, presentation |

### 2.3 Lộ trình

| Tháng | Trọng tâm | Target |
|-------|-----------|--------|
| 1–2 | Vocabulary + Grammar cơ bản | Nền tảng |
| 3–4 | Listening + Reading | TOEIC 500 |
| 5–6 | TOEIC practice + Professional English | TOEIC 650 |
| 7–30 | Maintenance + Professional usage | Duy trì |

### 2.4 Evidence

- TOEIC score report
- Listening practice logs
- Vocabulary lists
- Reading comprehension notes
- Professional English samples

## 4. Language Session

### 4.1 Cấu trúc

Mỗi language session gồm:

| Field | Mô tả |
|-------|-------|
| Language | English / Chinese |
| Skill | Kỹ năng luyện tập |
| Topic | Chủ đề |
| Source | Nguồn học |
| Duration | Thời lượng |
| Notes | Ghi chú |
| Output | Output tạo ra |
| Usefulness | Đánh giá hữu ích |
| Linked Mission | Mission liên kết (nếu có) |

### 4.2 Phân biệt

- Language session ≠ Evidence
- Language session là quá trình học
- Evidence là bằng chứng năng lực (TOEIC score, HSK score, samples)

## 6. Language in Weekly Plan

Language sessions phải được đưa vào Weekly Plan:

- **FOUNDATION (1–6):** English ưu tiên, 3–4 sessions/tuần
- **BUILD (7–12):** Chinese bắt đầu, English maintenance, 2–3 sessions/tuần
- **GROWTH (13–18):** Chinese ưu tiên, English professional, 2–3 sessions/tuần
- **INTEGRATION (19–24):** Chinese HSK4, English professional, 2 sessions/tuần
- **CONSULTANT (25–30):** Business Chinese, English professional, 1–2 sessions/tuần
